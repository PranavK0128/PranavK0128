### [Prompt Compression for Efficient Text Classification](https://github.com/PranavK0128/Prompt-Compression-For-Efficient-Text-Classification)
A collaborative NLP study comparing random, IDF, and learned compression for DistilBERT sentiment classification. We evaluated accuracy, input length, and complete inference cost across 43 configurations and three seeds.

[Code & results](https://github.com/PranavK0128/Prompt-Compression-For-Efficient-Text-Classification) · [Paper](https://github.com/PranavK0128/Prompt-Compression-For-Efficient-Text-Classification/blob/main/Prompt_Compression_Final_Report.pdf) · [Case study](https://pranavkondapalli.com/projects/prompt-compression)

### [Machine Learning for Poker Opponent Modeling](https://github.com/PranavK0128/Machine-Learning-for-Poker-Opponent-Actions)
Research on predicting opponent actions from player history, using tree ensembles and chronological evaluation alongside stored CFR+/DCFR policies. The public repository includes research code, methodology, notebooks, and aggregate results.

**Python · LightGBM · XGBoost · CatBoost · scikit-learn**

[Research repository](https://github.com/PranavK0128/Machine-Learning-for-Poker-Opponent-Actions) · [Paper](https://github.com/PranavK0128/Machine-Learning-for-Poker-Opponent-Actions/blob/main/report/main.pdf) · [Case study](https://pranavkondapalli.com/projects/pokernow-assistant)
